# PlayerLeash Plugin

Плагин для сервера Minecraft (Purpur 1.21.1), который позволяет привязывать игроков поводком и ограничивать их движение и действия.

## Функционал

- Привязывание игроков: Правый клик по игроку с поводком (LEAD) в руке для привязки/отвязки
- Блокировка движения: Привязанные игроки не могут двигаться
- Блокировка действий: Привязанные игроки не могут ломать и ставить блоки, а также атаковать

## Сборка

Для сборки плагина необходимо:

1. Установить Java 21 или выше
2. Установить Maven

Затем выполните в папке проекта:
```bash
mvn clean package
```

Готовый JAR файл будет в папке `target/PlayerLeash-1.0.0.jar`

## Установка

1. Скопируйте собранный JAR файл в папку `plugins` вашего сервера Purpur
2. Перезапустите сервер
3. Плагин автоматически загрузится

## Использование

1. Возьмите поводок (LEAD) в руку
2. Нажмите ПКМ (правый клик) на игроке, которого хотите привязать
3. Игрок будет привязан и не сможет двигаться или использовать предметы
4. Чтобы отвязать игрока, снова нажмите ПКМ на нем с поводком в руке

## Технические детали

- Версия API: 1.21.1
- Зависимости: Paper API (provided, совместим с Purpur)
- Язык: Java 21
